# 🌱 EcoMate - Smart Waste Management System

A modern web-based waste management system that optimizes collection routes and monitors bin fill levels in real-time.

## ✨ Features

- 🗺️ **Interactive Map**: Real-time waste bin locations with Google Maps integration
- 📊 **Smart Dashboard**: Analytics with distance, CO2 savings, and efficiency metrics
- 🚛 **Route Optimization**: Automatic route planning for collection vehicles
- 👥 **User Management**: Admin and user roles with different permissions
- 🌓 **Dark/Light Theme**: Professional UI with theme switching
- 📱 **Mobile Responsive**: Works perfectly on all devices
- 📈 **Data Export**: CSV export functionality for reports
- 🔔 **Real-time Notifications**: Success/error feedback system

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: PHP 8.x
- **Database**: MySQL 8.0
- **Maps**: Google Maps JavaScript API
- **Containerization**: Docker & Docker Compose
- **Styling**: Modern CSS with CSS Variables for theming

## 📦 Quick Start (Local Development)

1. **Clone the repository**
   ```bash
   git clone [your-repo-url]
   cd eco-waste-bridge
   ```

2. **Start with Docker**
   ```bash
   docker-compose up -d
   ```

3. **Access the application**
   - Open: `http://localhost:8080`
   - Login with demo credentials above

## 📋 System Requirements

- Docker & Docker Compose
- Google Maps API Key
- Modern web browser
- Internet connection (for maps)

## 🎯 Project Objectives

- Optimize waste collection routes to reduce fuel consumption
- Monitor bin fill levels in real-time
- Provide analytics for environmental impact (CO2 savings)
- Streamline waste management operations
- Reduce operational costs through smart routing

## 📊 System Architecture

- **Frontend**: Single-page application with responsive design
- **Backend**: RESTful PHP APIs for data management
- **Database**: Normalized MySQL schema for users and bins
- **Integration**: Google Maps API for mapping and routing
- **Deployment**: Containerized with Docker for consistency

## 🔧 Configuration

1. **Google Maps API**: Get API key from Google Cloud Console
2. **Database**: MySQL with proper user permissions
3. **Environment**: Set production environment variables
