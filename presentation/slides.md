# Eco-Waste Logistics Bridge — Presentation Outline

## Slide 1: Title
- Eco-Waste Logistics Bridge (EcoMate Command Center)

## Slide 2: Problem
- Waste bins fill up over time
- Need an efficient logistics planning approach
- Require monitoring + decision support

## Slide 3: Solution
- Web-based interactive command center
- Map visualization + routing analytics
- Admin simulation of bin fill levels

## Slide 4: Key Features
- Login system (admin/user)
- Role-based access controls
- CRUD for bins (admin)
- Live map markers and route analytics

## Slide 5: System Design
- ERD: users + bins tables
- Flow: UI -> APIs (get/manage) -> DB
- Route calculation uses Google Directions API

## Slide 6: Demo Flow
1. Start Docker
2. Open dashboard
3. Login as user
4. Observe disabled CRUD
5. Login as admin
6. Create/update/delete bins
7. Watch markers + route update

## Slide 7: Conclusion
- Working demo application
- Ready for reporting and presentation
